Seven-bit only: a radio mast drawn with slashes, pipes and hyphens, nothing outside plain ASCII. It renders the same in a terminal, in an email, in a text file from 1985. The rule is the opposite of dither, which uses nothing but the extended blocks. A sibling of tape.
